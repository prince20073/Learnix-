LEARNIX TEACHER PORTAL — PREMIUM UI UPDATE

What changed:
- Teacher navigation sections now open as focused, dedicated workspaces instead of leaving the overview dashboard stacked above the selected content.
- Overview-only widgets are hidden while another section is active and restored when Overview is selected.
- Section pages have improved spacing, stronger visual hierarchy, refined card surfaces, focus states, responsive layout, and dark-theme support.
- Existing teacher functionality and browser-storage behavior are preserved.

How to run:
1. Extract the full LEARNIX folder.
2. Open index.html using VS Code Live Server.
3. Sign in as a teacher.
4. Select each sidebar section to see its dedicated workspace.

Data note: this is still a front-end prototype. Browser-stored changes are local to this browser and are not automatically shared between teachers and students.
