LEARNIX STUDENT UX UPDATE

What's improved in this build:

1. Consistency Score
- Add personal tasks with a category and optional target date.
- Mark tasks complete/incomplete, see completion progress, and delete tasks.
- Keep the four daily habits separate from personal tasks and academic grades.
- Personal task list is saved in browser storage for the signed-in demo account.

2. My Courses
- Search courses by course name.
- Sort courses by recommended order, progress low-to-high, progress high-to-low, or name.
- See course count, average illustrative progress, and a suggested next step.
- Open a course or add a 25-minute study session to the study planner.
- Clearer cards and mobile responsive layout.

3. Early Warning
- Student-friendly assignment, CGPA goal, and upcoming-deadline signals.
- Action plan checklist with five practical actions.
- Clear next-step guidance and links to assignments, marks, deadlines, and planner.
- Explicitly labels examples and avoids presenting demo data as an actual prediction.

4. Profile photo upload
- Supports JPG/JPEG, PNG, and WebP up to 5 MB.
- Automatically resizes large images to a maximum 1200px dimension and compresses them as JPEG for more reliable local saving.
- Preview, remove, drag-and-drop, invalid-file feedback, and loading/read errors handled.

Run by opening index.html with VS Code Live Server. This remains a front-end demo: student data is stored in browser storage, and sample course/academic values are not official university records.
