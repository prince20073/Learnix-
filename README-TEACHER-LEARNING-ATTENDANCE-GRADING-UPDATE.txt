LEARNIX TEACHER PORTAL — WORKFLOW UPDATE

What's updated
1. Learning insights
   - Plain-language explanations for attendance, score, and workflow indicators.
   - Class filter, next-step suggestions, refresh action, and CSV export.
   - Labels make clear that sample scores are illustrative and are not automated decisions.

2. Attendance register
   - Add, edit, and delete students in the local roster.
   - Mark all present or absent for a selected date.
   - Save attendance per class and date; update a saved register by choosing the same class/date.
   - Summary cards and an attendance overview show present count, rate, saved registers, and students to check in with.
   - Button text is now “Save attendance” (the word “demo” has been removed).

3. Grading & feedback
   - Search the grading queue and add student submissions.
   - Record a mark from 0–100 and feedback; save as a draft or return it.
   - Review returned marks, edit feedback, or reopen a submission.
   - Summary cards show pending count, returned count, and average recorded mark.

4. Assignments & deadlines
   - Search and filter assignments by upcoming / overdue status.
   - Local assignments can be edited or removed, with due-date validation and summary counts.
   - Shared assignments are labelled and must be managed through the connected workspace.

5. My classes
   - Existing add/edit/remove, search, sort, and class overview tools remain.
   - Duplicate a class to reuse its setup, then edit the copy.
   - Export a class summary to CSV from the class overview.

Data and privacy
- This project continues to use browser storage for local teacher records. Local roster, attendance, grading and class changes are not automatically shared across devices or users.
- Included student names/scores are illustrative sample records. Confirm all official records and institutional grading policies before using them for real decisions.
- Shared institutional data requires a configured backend and appropriate access controls.

Run
Open index.html through VS Code Live Server, sign in as a teacher, then open Learning insights, Attendance, Grading & feedback, Assignments, and My classes.
