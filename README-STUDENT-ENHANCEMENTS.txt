LEARNIX STUDENT PORTAL - STUDENT EXPERIENCE UPDATE

Updates in this build:
1. Profile image now appears in the top-right account avatar and the sidebar avatar, as well as the profile card. Saving or removing a profile image refreshes all visible identity locations.
2. My Courses includes an Add Subject flow. User-created subjects can be edited, deleted, searched, sorted, assigned a progress percentage, and added to the study planner. Custom subjects persist in the existing per-student browser storage.
3. Attendance includes a circular attendance visualization, attended/missed summary, subject-level horizontal progress bars, status guidance, and a catch-up action that opens the planner. Attendance values are clearly labelled illustrative demo data.
4. Study Planner now includes planned session and time summaries, study date, focus type, priority, quick templates, and a richer upcoming-session list. New sessions are saved to the current student's browser storage.

How to run:
- Extract the ZIP.
- Open LEARNIX/index.html using VS Code Live Server.
- Use the student portal navigation to open My profile, My courses, Attendance, and Study planner.

Storage note:
This is a front-end prototype. Data is stored in the browser for the signed-in demo account. Attendance examples are not official university records.
