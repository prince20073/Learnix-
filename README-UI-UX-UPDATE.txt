LEARNIX STUDENT PORTAL — UI/UX UPDATE

What changed:
- Momentum Radar now uses a visual circular readiness gauge with improved layout and contrast.
- Assignment Deadlines uses clearer pending/completed progress cards and responsive layouts.
- Early Warning uses visual ring indicators for attendance, pending work, and progress toward the CGPA goal. Demo attendance is explicitly labeled as sample data.
- Consistency Score now uses a donut-style score visual and an easier-to-scan habit checklist.
- Academic current CGPA and target CGPA can be edited directly from My Profile > Edit profile. The Academic goals form in Settings is also functional.
- New student profiles default to CGPA 7.50 and target CGPA 7.50. Existing saved profiles keep their saved values so prior user data is not overwritten.
- CGPA displays and the overview progress bar now use the saved academic value.

Note: this is a front-end prototype; sample attendance and course data are not verified university records. User edits are stored in browser localStorage unless a backend is connected.

Run by extracting the ZIP, opening the folder in VS Code, and launching index.html with Live Server.
